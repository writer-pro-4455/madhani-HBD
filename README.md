# Madhani Birthday Adventure 🎂🎁

Interactive birthday website for Madhani, built for GitHub Pages.

## Password
`vachu2224`

> Madhani _ lam venam 😭😂 athellam illama podunga… open aagum 😌🔐🎁✨

## Videos
Place the two birthday videos here:
- `assets/videos/video1.mp4`
- `assets/videos/video2.mp4`

The videos are the main gifts and are revealed through the games.

## Features
Animated password gate, birthday intro, dietitian/nutrition jokes, catch-the-gifts game, hidden gift hunt, quiz, two video gift reveals, confetti, sound effects, and a candle-wish finale.

## GitHub Pages
Deploy the `main` branch from the repository root in Settings → Pages.
